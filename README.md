# Minijuegos de lógica de programación

Un minijuego nuevo cada jueves para aprender lógica de programación desde cero, en español y sin instalar nada.

**Jugar:** https://sarasederap.github.io/minijuegos-logica/

| Semana | Concepto | Juego |
|---|---|---|
| 1 | Variables | [semanas/01-variables](semanas/01-variables/) |

Plan: variables → condicionales → bucles → funciones → listas → recursión → ordenar y buscar.
El archivo `registro.json` guarda qué conceptos se han cubierto ya.
